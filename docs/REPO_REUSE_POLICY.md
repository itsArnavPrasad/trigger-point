# Repository Reuse and Code Provenance Policy

## Before borrowing code
For every reference repository:
1. Read the current `LICENSE` and any `NOTICE`, contribution, or additional-terms files.
2. Record repository URL, commit SHA, retrieval date, relevant file paths, and the reason for inspection.
3. Check dependencies, open issues, recent maintenance, security alerts, and tests.
4. Prefer learning architecture and reimplementing the smallest needed pattern over importing an entire stack.
5. If code is copied or adapted, retain required notices and record modifications.
6. Do not copy secrets, sample prospect data, user records, or personal data.
7. Run dependency and license checks before shipping.

## Specific caution
TREG's current repository license includes additional restrictions on hosted/managed/embedded third-party services without prior written authorization. Treat it as research-only unless legal review and explicit permission resolve this.
